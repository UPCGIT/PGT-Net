# PGT-Net
# A Prompt-Guided Transformer Network With Redundancy-Aware Endmember Bundles Considering Spectral Variability for Hyperspectral Unmixing
The code in this toolbox implements the "A Prompt-Guided Transformer Network With Redundancy-Aware Endmember Bundles Considering Spectral Variability for Hyperspectral Unmixing".
# System-specific notes
The code was tested in the environment of `Python 3.10.19`, `torch 2.9.1` and `CUDA 12.8`.
